TSL - GUI Icon Overhaul by PramodMarlon
================================================

 Thank you for downloading my mod.
 
 1.)Installation
 ---------------
    Just Drag all the 1200+ files to your TSL override Folder
	
 2.)Uninstallation
 -----------------
    Remove all the files that you moved from this mod to your TSL Override Folder
	
 3.)Compatability
------------------
    Should cause no issues whatsoever, I already tested just in case with thousands of mods in my override folder. 
	If you have other mods that replace icons, install them after this.
	If you already have icon files in you override folder, don't replace them as some mod you're using likely needs them.
